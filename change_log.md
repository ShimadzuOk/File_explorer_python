# Change log for File_explorer_python

## *0.1.0 (First version)*

Supported actions:
- Selecting starting dir
- Opening files in respective software
- Differentiating icons for dirs, files and archives
- Going back on previous dir
- Pop up menu supporting: 
    1. Refresh
    2. Sort
    3. Creating new 
    4. Deletion
    5. Placeholders for copy, paste and rename options
- Info tab showing stat data

## *0.2.0*

### Changes:
- Major code review and overhaul, refresh function inparticular
- copy buffer was added(just a var)
- Bug fixes

New addition:
- Rename function fully operational
